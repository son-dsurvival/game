# Issue tracker: Local Markdown

Issues and specs for this repository live under `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`
- Spec: `.scratch/<feature-slug>/spec.md`
- Tickets: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`
- Use one file per ticket, numbered from `01` in dependency order.
- Record triage state with a `Status:` line.
- Append discussion under `## Comments`.

When a skill publishes tickets, it creates the relevant feature directory and individual issue files.
